# 星环乱斗

浏览器对战游戏。此仓库同时包含网页和在线房间服务器，部署后同学可以使用同一个公网网址进入游戏。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Ffoxmars%2F-)

点击上方按钮，在 Render 中检查并部署 `render.yaml`。配置使用常驻 Starter 实例，部署会产生费用，确认价格后再完成付款。部署成功后，分享 Render 给出的 `https://…onrender.com/` 游戏网址。

本机运行：`node server.cjs`，然后打开 `http://localhost:8787/`。
